# Access and source rights

The source CSV and HTML dashboard contain the exact submitted prompts, including full news article text from BBC and a Reuters article carried by Internazionale. Publisher text remains subject to its original rights; inclusion in this research snapshot does not grant a license to redistribute publisher text. No broad data license is granted here.

Model responses are archived research observations. Model names and provider identifiers are preserved as recorded labels, not independently verified backend identities. The report and code document transformations without altering the canonical responses.

The HTML dashboard has no external script, font, stylesheet, analytics, or API dependency. Opening it locally does not upload the dataset. It includes ordinary source hyperlinks that navigate externally only if selected.

The repository contains the selected 28-column CSV only, not account credentials, browser histories, account screenshots, or experiment chat links from the wider collection environment.
