Each response is matched on the source article, prompt family and exact Y identity. Between-model distances therefore compare answers to the same full prompt.

Semantic distance describes a difference in encoded meaning. It does not by itself establish prejudice, harmful treatment, factual error or model quality.

    Identity sensitivity measures within-model response distance when the Y identity changes and article and prompt family remain fixed. The identities are experimental prompt inputs.

    Methods, definitions & interpretation
    What each quantity measures
    Text preparation
    Leading “Gemini said” and “Response N:” interface headers are removed, and whitespace is normalized before analysis. Original responses remain intact in the CSV and explorer.
    Matched-prompt distance
    Cosine distance between response embeddings from two different models given the exact same source article, family and Y label.
    Exact-label masking
    The MPNet masking check replaces case-insensitive, word-bounded matches of the 42 supplied Y labels with [IDENTITY]. Synonyms, paraphrases and indirect identity cues remain. This is a lexical sensitivity check, not removal of all identity information.
    TF–IDF baseline
    Cosine distance over lexical unigram/bigram weights. This is a lexical comparison rather than a neural semantic encoder.
    Cosine distance
    1 − cosine similarity. Smaller values indicate a closer embedding direction. Its magnitude depends on the encoder; compare values within an encoder.
    Identity sensitivity
    Average distance between a model’s responses to different Y identities in the same dimension, while source article and prompt family stay fixed.
    Confidence interval
    Uncertainty intervals are displayed only when present in the computed result tables. Refer to the report and analysis code for the resampling unit and assumptions.
    X group
    The news article used as source evidence. X is held fixed in a matched comparison.
    Y group
    The stated reader identity in the question. Y dimensions include socioeconomic position, race/ethnicity, religion, politics, geography, and gender/sexuality.
    Model/company contrast
    An observed difference between labelled model deployments. Same-company similarity does not establish an evolutionary trajectory.
    What this study cannot identify
    One response per matched model–prompt cell does not separate model-level behavior from generation variability. Collection dates, product interfaces, model tiers and backend changes may also affect comparisons.
    Two source articles and seven question families constrain generalization. Most Y labels occur in deliberately personalized prompts, so some identity-dependent differences are task-relevant.
    Distance may reflect wording, length, shared boilerplate, topic selection or substantive framing. Inspect the underlying responses before attributing a distance to bias.
    Raw responses may contain copied interface text, citation tokens or template fragments. The audit results and preprocessing code determine which content was analyzed. The response explorer always shows the retained dataset text.
    Neither lower distance nor greater similarity to a particular model defines fairness, accuracy or quality. These require separately specified criteria and appropriate evaluation.
    The dashboard makes the analysis inspectable. Scientific claims should use the report’s definitions, sensitivity checks, limitations and exact encoder configurations.
