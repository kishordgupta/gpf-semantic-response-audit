# Scientific report

**Authors:** Kishor Datta Gupta and Mohd Ariful Haque.

Read the [full report PDF](main.pdf). The editable report is maintained separately in Overleaf; the project identifier is not included in this release.

The report includes the complete 28-column dictionary; all 42 Y labels, both aggregated and by model; all 66 model-pair MPNet estimates with full/screened means; same-company and cross-company comparisons; article/family strata; source-proximity diagnostics; length and representation sensitivities; eight inspectable paired cases; quality anomalies; uncertainty, provenance, and causal-inference limits.

The numerical analysis is reproducible from the repository's dataset and code; its complete tables are available in the result CSV/JSON files. `curated_cases.json` records the qualitative case evidence. Each excerpt was checked against its saved response. The prose does not equate distance with harmful bias or improvement. Case selection is purposive and explicitly not a prevalence estimate. The five suspect Gemini conditions are not used as qualitative examples.

The GitHub report artifacts are the PDF and supporting metadata. Use Overleaf for report editing.
